# 42 Genesis Blocks: Whitepaper

*Version 1.0, artist `khbouych`, 42 TokenizeArt project.*

## Abstract

**42 Genesis Blocks** is a digital artwork issued as a BEP-721 non-fungible token on BNB Smart Chain Testnet. The artwork renders the number 42 as gold blocks on a grid of empty blocks, a visual nod to the blocks that make up a blockchain. Ownership is recorded on-chain, and the artwork and its description live on IPFS, linked by content hashes, so the token, its metadata and its image form a chain that cannot be silently altered.

## 1. Concept

A blockchain is a sequence of blocks, and the first one is the **genesis block**. This piece treats the number 42 as a genesis: the first NFT of its artist, built literally out of blocks. Each gold square is one "block"; the dark squares around it are the empty grid from which the chain grows.

The design follows three rules:

- **Legibility.** The 42 must read unambiguously, even as a small thumbnail. The digits are hand-made bitmaps with two-block-thick strokes, and the 2 has a rounded top so it cannot be mistaken for a Z.
- **Determinism.** No fonts are used. The image is generated by code (`code/scripts/generate-art.ts`), so anyone can regenerate the exact same artwork from the repository.
- **Clarity.** One subject, high contrast: gold (BNB Chain's color) on deep navy.

## 3. Features and functionality

- **Verifiable ownership.** `ownerOf(0)` returns the current owner to anyone, at any time, for free.
- **Transferable.** The owner can transfer or approve the token with standard ERC-721 calls; any compatible wallet can move it.
- **Permanent link to the art.** `tokenURI(0)` returns the metadata's IPFS address. There is no function to change it, and IPFS addresses are content hashes, so the artwork bound to the token is fixed.
- **Controlled issuance.** Only the contract owner can mint (`safeMint`), and ownership can only change hands through a two-step transfer that the new owner must accept.
- **Open source and verified.** The contract source is public in this repository and verified on Sourcify against the deployed bytecode.
- **Wallet and explorer support.** As a standard BEP-721 token, it shows up on BscScan and can be imported into wallets such as MetaMask.

## 4. Security

The contract builds on OpenZeppelin Contracts 5.6.1. It passed 15 unit tests and a Slither static analysis with no findings, and no secret appears anywhere in the repository history. The owner cannot move holders' tokens, change metadata, or take funds. The full analysis, including known limitations (a single-key owner, a test wallet key kept in a local file), is in [security.md](security.md).

## 5. Scope and limits

This is an educational project on a **testnet**: the token has no monetary value, and no real funds were used at any point, as the subject requires. The artwork's availability depends on the IPFS files staying pinned. If they were ever dropped, re-uploading the files from `code/art/` restores them at the same addresses, with no change on-chain.
